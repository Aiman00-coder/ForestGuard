# 🌿 ForestGuard — Forest Conservation Website

## 🌍 About the Project

ForestGuard is a forest conservation awareness website developed using HTML, CSS, and JavaScript. The main goal of this project is to spread awareness about the importance of forests, wildlife protection, deforestation prevention, and environmental sustainability.

The website encourages people to take small steps toward protecting nature and creating a greener future.

## ✨ Features

- **Home Section:** Introduces the importance of saving forests.
- **About Section:** Explains the benefits of forests, including clean air, water conservation, climate protection, and biodiversity.
- **Threats to Forests:** Highlights deforestation, forest fires, habitat loss, and pollution.
- **Wildlife Protection:** Showcases the importance of protecting animals and their natural habitats.
- **Take Action Checklist:** Allows users to check off eco-friendly actions.
- **Progress Bar:** Displays the progress of completed conservation actions.
- **Responsive Design:** Adapts the website layout to different screen sizes.
- **Interactive Navigation:** Provides a mobile-friendly navigation menu.

## 🛠️ Technologies Used

- HTML5 — Website structure and content
- CSS3 — Styling, layouts, colors, and responsive design
- JavaScript — Interactive checklist, progress bar, and navigation functionality

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files (`index.html`, `style.css`, and `script.js`) are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code.

**Note:** An internet connection is required to load the external forest and wildlife photographs.
